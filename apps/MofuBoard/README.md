# もふもふボードゲーム

ボードゲームとパズルがたくさん入ったゲーム集です。ひとりでも、CPUとでも、1台のスマホをみんなで回しても、友だちとオンラインでも遊べます。
キャラクターは もふぴー・くろにゃ・ぴょんた・ぺんぺん・がおるん（添付イラストをそのまま切り抜いて使用。縦横同じ倍率で縮小するだけで、変形はしていません）。

## 収録ゲーム（20種）
アプリストアの人気ランキングや、定番ボードゲーム集（世界の定番ゲーム集など）の収録タイトルを調べて選びました。商標名は使わず一般名にしています。

**ひとりでパズル（7種）**
- 数独（かんたん／ふつう／むずかしい・自動生成・メモ・ヒント）
- ペグソリティア（練習8本／中級16本／本番32本）
- かさねて2048（4×4／5×5・スワイプ）
- スライドパズル（3×3〜5×5）
- じらいさがし（3段階・旗モード・長押しで旗）
- ヒット＆ブロー（色当て推理・3段階）
- ライツアウト（4×4〜6×6）

**対戦（CPU・1台でみんな・オンライン）13種**
| ゲーム | 人数 |
|---|---|
| リバーシ | 2人 |
| 将棋（持ち駒・成り・二歩/打ち歩詰め禁止・千日手・投了） | 2人 |
| チェス（キャスリング・アンパッサン・昇格・ステイルメイト等） | 2人 |
| 五目ならべ | 2人 |
| 四目ならべ | 2人 |
| チェッカー（取るのは強制・連続ジャンプ・キング） | 2人 |
| マンカラ（カラハ・種の数を選べる） | 2人 |
| ドット＆ボックス（3×3〜6×6） | 2〜4人 |
| ダイヤモンドゲーム（星形の盤・連続ジャンプ） | 2〜3人 |
| 陣取りブロック（21種のブロックを角でつなぐ） | 2〜4人 |
| ルド（すごろく陣取り） | 2〜4人 |
| もふもふすごろく（オリジナル・イベントマス） | 2〜5人 |
| ヨット（ダイス役づくり） | 1〜5人 |

- **CPUと対戦**：人数が足りない分をCPUで埋められます。強さは「やさしい／ふつう／つよい」。将棋・チェス・リバーシ・四目・チェッカー・マンカラは先読み（αβ探索）で考えます。
- **みんなで（1台で）**：1台のスマホを順番に回して2〜5人で。CPUを混ぜることもできます。

## オンライン対戦（招待コード）
- 「オンライン対戦」→「部屋をつくる」→ 人数を選ぶと **6けたの招待コード** ができます（1けた目が人数）。
- 「コードを送る」で LINE などに送れます。友だちは「コードで参加」に入力。
- 全員そろうとロビーへ。ホスト（部屋を作った人）がゲーム・CPUの人数・強さを選んでスタート。
- 仕組み：Game Center のリアルタイム対戦（GameKit）。招待コードを `playerGroup` に使うので、同じコードの人どうしだけがつながります。サーバーは不要です。
- ホストがゲームの進行を計算して全員に配り、参加者は操作だけを送ります。途中で抜けた人の席はCPUが代わりに遊びます。
- 将棋・チェスなどは、自分の駒が手前にくるように盤が回ります。

## 中身
- `Resources/index.html`, `style.css` … 画面
- `Resources/core.js` … 共通（セーブ・効果音・キャラ）
- `Resources/kit.js` … ボードゲーム共通の道具（盤の配置・さいころ・CPU用の時間制限）
- `Resources/games1.js` … リバーシ・五目・四目・マンカラ・ドット＆ボックス
- `Resources/games2.js` … チェッカー・ダイヤモンドゲーム
- `Resources/shogi.js`, `chess.js` … 将棋・チェス（ルールとCPU）
- `Resources/games3.js` … すごろく・ルド・ヨット
- `Resources/blocks.js` … 陣取りブロック
- `Resources/puzzles.js` … ひとりパズル7種
- `Resources/table.js` … 対戦の進行・CPU・1台モード・同期
- `Resources/net.js` … オンライン（招待コード・ロビー）
- `App/GameCenterManager.swift` … Game Center の接続（招待コード検索・招待・送受信）
- `App/GameView.swift` … 画面表示とアプリの橋渡し（セーブ・振動・共有）

ブラウザで `Resources/index.html` を開くと動作確認できます（同じブラウザの別タブ同士で、オンライン対戦のテストもできます）。

## iPhone への入れ方
`main` に push すると GitHub Actions の「もふもふボードゲーム iOS / TestFlight」が動き、TestFlight にアップロードされます。
初回だけ App Store Connect で次の作業が必要です。
1. 「マイApp」→「＋」→「新規App」で Bundle ID `com.yosiken0421.mofuboard` のアプリを作成
2. TestFlight の内部テスターに自分を追加
3. （オンライン対戦用）そのアプリで Game Center を有効にする

アプリ作成後にもう一度アップロードしたいときは、Actions の「もふもふボードゲーム iOS / TestFlight」で Run workflow を押します。

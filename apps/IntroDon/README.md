# イントロどんぴしゃ（イントロクイズ）

イントロを聴いて曲名を当てる iPhone アプリ。SwiftUI ネイティブ。

## 遊び方
- **番組ルール**（クイズ・ドレミファドン！のイントロクイズを参考）：イントロ（5点）→ウルトラ（10点）→超ウルトラ（20点）の3ステージ。ステージごとにイントロが短くなる。不正解は−5点で✕、1ステージで✕2つになると失格（得点没収）。曲の再生中でも回答できる（早押し）
- **フリープレイ**：1問1点、減点なし、「+1秒で聴く」あり
- 曲の止め方：「自分で止める」（初期設定。ドン！で流れ続け、ストップで停止、つづきを流す／最初からで再開。聴いた秒数を表示）か「秒数で自動で止める」
- 答え合わせのあとの「続きを聴く」は曲の最後まで流れる（もう一度押すと止める）
- 「答えを見る」ボタン、答えの音声読み上げ、正解◯（紙吹雪）／不正解✕（揺れる）のモーション

## 有名 / マイナー
- 有名：`Resources/hits.json`（約3,500曲）から出題。1970〜2007年はオリコン年間シングル上位（30位まで。1991・1995〜1997・2000〜2007年は Wikipedia「○年の音楽」から50位まで）、2008〜2025年は Billboard JAPAN 年間HOT100（100位まで。2009・2010年は50位まで）。年間ランキングの追加は `.github/workflows/introdon-charts.yml`、洋楽は米 Billboard Hot 100 の1位曲。年代はランキングの年
- アニメ：Billboard JAPAN 年間Hot Animation（2016・2019・2020・2022・2024・2025年）、NHK『ベスト・アニソン100』（2017年）、テレビ朝日『アニメソング総選挙』（2020年）、『世界アニソン総選挙』（2024年）、『アニソンランキング』昭和・平成・令和ベスト20（2023年）の約230曲（hits.json の g=anime）。年が不明な曲は Apple の発売年で年代を確認
- ヒップホップ：米Billboardラップチャート1位曲（1989〜2019年）、RAG MUSIC「邦楽ヒップホップ人気ランキング」（ユーザー投票）と、そこに入っている歌手の年間ランキング曲
- ダンス：米Billboard Hot Dance/Electronic Songs 1位曲（2013〜2016・2022・2024・2025年）＋Appleのジャンルがダンス／エレクトロニック／ディスコの曲
- マイナー：その年代・ジャンルのヒット歌手の、リストに入っていない曲
- 最近のゲームで出た曲（この iPhone で直近600曲）は後回しにして、続けて遊んでも同じ曲が出にくいように
- アーティストで選ぶ：ヒット曲リストの歌手（邦楽・洋楽、よみでも検索可）を複数選ぶと、その人たちの曲だけで出題（ジャンルでは絞らない、年代はそのまま）。1曲からでも遊べて、問題数はある曲の数まで。選択肢は同じ年代のほかのヒット曲から作る
- 順位で選ぶ：TOP10だけ／TOP30まで／100位まで（＋順位のない投票企画など）。生まれ年モードにも効く
- 選択肢は同じ種類の曲から作り、これまでの答えと直前の選択肢は使わない
- 有名な曲は年間順位の高い曲ほど出やすい（重み付きシャッフル。1〜10位:6、11〜20位:3、21〜30位:1.5、31〜50位:1、51位〜:0.7、アニソン投票:5、米1位:3／全ジャンルでは1）

## Apple の曲データとの照合（ジャンル・原曲）
GitHub Actions「イントロどんぴしゃ 曲データの照合」（`.github/workflows/introdon-enrich.yml`、`.github/scripts/introdon_enrich.py`）で、
hits.json の全曲を iTunes Search API と照合し、原曲の trackId（`id`）・ジャンル（`ag`）・歌手名（`aa`）・発売年（`ry`）・長さ（`ms`）を書き込む。
- 曲名一致＋歌手一致（短い名前は完全一致のみ）。ライブ・カラオケ・オルゴール・インスト・カバー等は除外し、発売日が古い版を優先
- 曲リストを変えたら「Run workflow」で再実行
- ジャンル分け：ロック／ヒップホップ／ダンス＝Appleのジャンル（邦楽・洋楽とも）、J-POP＝邦楽でJ-Pop（アニメ含む）、演歌・歌謡曲＝邦楽で演歌・歌謡曲、洋楽＝米Billboard 1位曲、アニメ＝アニソンランキングの曲かAppleのジャンルがアニメ
- 年代とジャンルで曲が足りないときは、「前半・後半」を同じ年代まるごとに広げるだけ（別の年代には広げない。広げたら画面に表示、選んだ年代の曲を先に出題）。それでも足りない年代×ジャンルはボタンを押せない（例：90年代の演歌・ダンス、80年代以前のアニメ・ヒップホップ・ダンス）
- マイナー曲は、選んだ年代より10年以上前からヒットのある歌手の曲（昔の曲の再発売の可能性が高い）を除き、発売年が範囲内のものだけ

## 読み上げ
- 曲名・歌手名の読みは、GitHub Actions「イントロどんぴしゃ 読みの収集」（`.github/scripts/introdon_readings.py`）で日本語版 Wikipedia の記事の書き出し「「曲名」（よみ）は…」「歌手名（よみ、…）は…」から集めて hits.json の `rt`・`ra` に入れる。名前が一致し、読みがかなだけで、元の名前のかなが同じ順番で読みに入っているものだけ採用
- 読みがある名前は読みで、洋楽は英語の声で、日本の曲の英字部分は英語の声で読む
- iPhone に入っているいちばん品質の高い声（プレミアム→拡張→標準）を使う。区切りごとに少し間を入れる

## タイアップ表示
日本語版 Wikipedia の曲の記事を API で取得し、「主題歌」「オープニングテーマ」などと『作品名』が同じ文にあるときだけ、アニメ・ドラマ・映画などとして表示・読み上げ。

## 生まれ年でイントロドン
- 1990・91年生まれ〜2004・05年生まれの2年ごとのボタン（1年ごとだと前後の年でほぼ同じ曲になるため）
- 生まれ年の10歳〜18歳の年（例：1994・95年生まれ→2004〜2013年）の年間ランキングに入った曲だけで出題。年代は広げない。マイナー曲は使わない
- ランキングの年が範囲内でも、元の曲がその範囲より前に出た再ヒット曲（Appleの最初の発売年が範囲の1年前より前）は使わない。年間ランキングの年がない曲（アニソン投票など）も使わない
- その範囲で10問分＋予備4曲以上あるジャンルだけボタンを出し、押すとすぐ開始

## 年代
全年代、各年代まるごと（70年代〜2020年代）、5年刻み（前半・後半）。

## 曲の出どころ
| モード | 中身 | イントロ |
|---|---|---|
| iPhoneのミュージック | 端末のライブラリ（MPMediaQuery） | 曲の頭から |
| Apple Music | iTunes Search API で曲を探し、MPMusicPlayerController（storeID）で再生。加入者のみ | 曲の頭から |
| 試聴音源（無料） | iTunes Search API の previewUrl（30秒）をストリーミング再生 | 途中から始まる曲あり |

## 再生する場所
- 「歌い出しから」：LRCLIB（https://lrclib.net、無料・APIキー不要）の同期歌詞から最初の歌詞行の時刻を取り、その約1.5秒前から再生。曲名・アーティスト・曲の長さ（±5秒）で照合し、見つからなければ曲の頭から。試聴音源モードでは使わない
- 「曲の頭から」：前奏から

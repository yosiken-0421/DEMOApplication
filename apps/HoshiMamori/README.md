# ほしまもりの塔（iPhone アプリ）

塔1本で夜空を守る、放置寄りのタワーディフェンスです。星座の形をしたスキルツリーで成長させます。
ゲーム本体は `Resources/index.html`（HTML5 Canvas）で、アプリはそれを全画面で表示する Swift の入れ物です（セーブと振動をアプリ側で担当）。

## 遊びの仕組み
| 仕組み | 通貨 | 残る？ | 内容 |
|---|---|---|---|
| 戦闘中の強化 | ⚡エナジー | 出撃ごとにリセット | 攻撃・守り・恵みの12項目 |
| 工房 | ✦かけら | ずっと | 12項目の「はじめの強さ」を上げる |
| 星座（スキルツリー） | ★星ポイント | ずっと（振り直し無料） | 攻撃・守り・恵みの3星座、21個の星。双子星・貫通・稲妻・流星群・不屈・自動強化・3倍速など、遊び方が変わる星 |
| 研究所 | ✦かけら＋時間 | ずっと | アプリを閉じていても進む。研究枠は最大3つ |
| 星の採掘場 | ✦かけら | — | 放置中にかけらがたまる（最初は最大4時間ぶん） |
| ティア | — | — | ウェーブ30突破で次のティア（敵HP×2.6、かけら×1.7） |
| 毎日 | — | — | ログインボーナス（7日目に★）、任務3つ（全部クリアで★） |
| 週替わり | — | — | 「今週の星回り」で毎週月曜にルールが変わる（5種類） |

★星ポイントは、各ティアでウェーブ10・20・30…を初めて突破したときにもらえます。

## TestFlight に入れる（PadGuide と同じ手順）
1. Safari でこのリポジトリを開き「**Actions**」
2. 左の一覧から「**ほしまもりの塔 iOS / TestFlight**」
3. 「**Run workflow**」→ `release_mode` は `testflight` のまま → 緑の「**Run workflow**」
4. 20〜40 分ほどで緑のチェック。いちばん下に日本語の結果の要約が出ます
5. App Store Connect →「ほしまもりの塔」→「TestFlight」→「内部テスト」の「＋」でグループを作り、自分を追加
6. iPhone の TestFlight アプリからインストール

`apps/HoshiMamori` を変更して main に push すると、自動で TestFlight まで実行されます。
API キー（ASC_KEY_ID / ASC_ISSUER_ID / ASC_KEY_P8 / APPLE_TEAM_ID）は PadGuide 用に登録済みのものを使います。

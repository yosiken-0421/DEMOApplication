# そらいろ冒険隊（iPhone アプリ）

放置×キャラ育成のオリジナルゲームです。ゲーム本体は `Resources/index.html`（HTML + SVG + Canvas）で、
アプリはそれを全画面で表示する Swift の入れ物です（セーブ・振動・通知をアプリ側で担当）。

## ゲームの中身
- 仲間 12 人（アニメ調・オリジナル）を雇ってレベルアップ。Lv10 で ×2、以降 25 レベルごとに ×3
- アプリを閉じていても仲間が戦い、コインが貯まる（最大 8 時間、強化で延長）。開くと「おかえり」報酬
- 5 ステージごとにボス（30 秒）、25 ステージごとに大ボス。6 つのエリア
- おやすみ（転生）：ステージ 40 から。そらの羽 1 枚でダメージ +10% がずっと続く
- 星のかけら：覚醒（★、ダメージ ×2）と永続強化に使う。ボス初撃破・図鑑登録・ミッション・ログインで入手
- 毎日のミッション、7 日のログインボーナス、実績、まもの図鑑 30 種
- スキル：全力（ダメージ ×3）、金の雨（コイン ×3）、星の矢（大ダメージ）
- 通知：宝箱がいっぱいになったとき／翌日 19:30 にミッションのお知らせ（最初のボス撃破後に許可を聞く）

## TestFlight に入れる（PadGuide と同じ手順）
1. App Store Connect の「マイApp」→「＋」→「新規App」で、Bundle ID `com.yosiken0421.sorairo` のアプリを作る（最初の 1 回だけ）
2. GitHub の「Actions」→「そらいろ冒険隊 iOS / TestFlight」→「Run workflow」
3. 20〜40 分ほどで緑のチェック。いちばん下に日本語の結果の要約が出ます
4. App Store Connect →「そらいろ冒険隊」→「TestFlight」→「内部テスト」で自分を追加
5. iPhone の TestFlight アプリからインストール

`apps/Sorairo` を変更して main に push すると、自動で TestFlight まで実行されます。
API キー（ASC_KEY_ID / ASC_ISSUER_ID / ASC_KEY_P8 / APPLE_TEAM_ID）は PadGuide 用に登録済みのものを使います。
Bundle ID の登録はワークフローが自動で行います。

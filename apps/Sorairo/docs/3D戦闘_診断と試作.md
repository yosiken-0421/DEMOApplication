# 3D戦闘：診断と試作の記録（2026-11-01）

## 1. 現状の診断
| 項目 | 結果 | 根拠 |
|---|---|---|
| エンジン | Unity でも Capacitor でもない。Swift の WKWebView で HTML/JavaScript を表示 | `App/GameView.swift`（`loadFileURL` で `Resources/index.html`）、`project.yml`（XcodeGen）。package.json・Unity プロジェクトなし |
| キャラの描画（従来） | 2D 画像（WebP）を DOM の `<img>` で表示し、CSS/Web Animations で移動・拡大・差し替え | `index.html` の `buildPartyInner()` `setView()` `pose()` `attackSeq()`、画像 `Resources/h{0-7}_{0-6}.webp` |
| 攻撃エフェクト | Canvas 2D | `index.html` の `drawShots()` `landShot()` |
| 3D モデル・骨格・アニメ素材 | **存在しない**（GLB/GLTF/FBX/Blend/VRM なし） | リポジトリ全体を検索 |
| 参考画像 | あり：1キャラ7枚（正面・右・背面・左・構え・攻撃・決め） | `art/hd/hero{k}_{n}.webp` |
| 敵 | 2D 画像のまま | `ART.mon` / `ART.monCut` |

結論：本物の 3D にするには、キャラ本体の 3D モデルとリグを新しく用意する必要がある。

## 2. この試作でやったこと（ブランチ `feature/sorairo-3d-battle`）
- three.js r170（MIT）を `Resources/three.min.js` として同梱（外部通信なし）
- `Resources/sorairo3d.js`：コードで組み立てた **骨格つきメッシュ（SkinnedMesh＋Skeleton、骨20本）**
  - 骨：root/hips/spine/chest/neck/head、左右の shoulder/upperArm/foreArm/hand、thigh/shin/foot
  - 関節まわりは2本の骨に重みを分けて、曲げても皮膚がちぎれないようにした
  - 頭・髪・武器は骨に固定（武器は手の骨のソケット）
  - AnimationMixer で Idle / Run / Attack を再生・ブレンド
- 対象：モモ（ガントレットの重いストレート）、ルル（杖を振りかぶって水の弾）、ノクア（大鎌の振り下ろし）
- 攻撃の時間配分（0.86秒）：予備 0–0.16 / 踏み込み 0.16–0.32 / 命中 0.32–0.43 / 振り抜き 0.43–0.60 / 復帰 0.60–0.86
- 命中フレームでダメージ・効果音・敵ののけぞり・接触位置のエフェクトを同時に出す（ルルは弾が届いた時）
- モーション中に次の攻撃が来たら、モーションは重ねずにダメージだけ入れる
- 設定画面の「3D戦闘（試作）」でオン/オフ（**初期はオフ**。オフなら従来どおり）

## 3. ゲームロジックの変更
- 仲間の自動攻撃のタイマーを、画面の描画間隔ではなく実際の経過時間で進めるようにした（`frame()`）。
  画面が重くなっても毎秒ダメージが下がらない。60fps 付近では従来と同じ値。

## 4. テスト（ヘッドレス Chromium・ソフトウェア描画）
- SkinnedMesh・骨20本・頂点 18,900 を確認
- 3方向から描いて輪郭が変わることを確認（平面画像ではない）
- 攻撃中に腕・胴・腰・脚の角度が時間とともに変わり、終わると待機に戻ることを確認
- 12秒間の与ダメージ：3Dオフ 7,342,720,480 / 3Dオン 7,344,960,520（差 0.03%）
- 既存の通し確認（ボス失敗→再挑戦・スキル・おやすみ・セーブ読み込み）：エラーなし

## 6. 設定画どおりの 3D にするために必要な作業
1. 3D モデル作成（1体ずつ）：参考画像7枚をもとに Blender で手作業、または画像から 3D を作るサービス（有料のものが多い）で下書きを作って Blender で修正
2. リギング：上の骨の名前・階層にそろえる（そろえれば `sorairo3d.js` のアニメーションをそのまま使える）
3. GLB 形式で書き出して `Resources/` に置き、`buildCharacter()` を GLTFLoader 読み込みに差し替える

## 7. ユキナを実際の3Dモデルに差し替え（2026-11-04）
- 元データ：ユーザー提供の Tripo 製 GLB（`art/3d/yukina_tripo.glb`）。骨・アニメーションなし、約101万頂点
- 約3万三角形・2.6万頂点に軽量化し、骨20本（他キャラと同じ名前・階層）を自動で割り当て → `Resources/model_h1.js`（約1.4MB）
- 顔・髪・衣装・槍はモデルのテクスチャそのまま（作り直していない）
- モーション：待機・走り・槍の突き（構え0–0.16／踏み込み0.16–0.32／突き・命中0.38／振り抜き〜0.60／戻り〜0.86）
- 槍の長さぶん手前で止まって突く。命中時に氷の結晶エフェクト・効果音・振動・敵のヒットストップ
- テスト（ヘッドレス Chromium）：骨20本の SkinnedMesh、エラーなし。12秒の与ダメージ 2D 7,325,123,167 / 3D 7,342,723,476（差0.24%）。既存の通し確認も問題なし
- 未確認：iPhone 実機での FPS・メモリ。スカートや長い髪は布の物理演算ではなく骨への重みで動かしている
- 手順の詳細：`tools/model3d/README.md`

# 3Dモデル（GLB）をゲーム用にする手順
元データ：`art/3d/yukina_tripo.glb`（ユーザー提供・Tripo 製、骨なし・約190万三角形）

1. `decode.mjs`：GLB の meshopt 圧縮をほどき、頂点・UV・三角形・テクスチャを取り出す（meshoptimizer の JS 版が必要）
2. `simplify.mjs`：UV を保ったまま約3万三角形に軽量化
3. 向きと大きさをそろえる：正面を +z、足を y=0、身長 2.85（`sorairo3d.js` の骨格と同じ単位）
4. `rig.py`：骨20本の位置をモデルに合わせて置き、頂点ごとの重みを計算
   - 槍は左手の骨に固定（つながりをたどって飾りの結晶まで含める）、槍と体をつなぐ三角形は削除
   - 頭と上の髪は頭の骨、下の髪は胸→背骨→腰へなめらかに追従
   - スカートは腰に固定し、脚のすぐ外側だけ脚に少し追従
5. `export.py`：`Resources/model_h1.js` に書き出す（座標は16bit、テクスチャは1024pxのJPEGを埋め込み）

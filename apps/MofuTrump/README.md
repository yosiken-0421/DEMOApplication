# もふもふトランプ

トランプゲームがたくさん入ったゲーム集です。ひとりでも、CPUとでも、友だちとオンラインでも遊べます。
キャラクターは もふぴー・くろにゃ・ぴょんた・ぺんぺん・がおるん（添付イラストをそのまま切り抜いて使用。変形はしていません）。

## 収録ゲーム（15種）
人気ランキングや定番アプリの収録タイトルを調べて選びました。

**ひとりで遊ぶ（ソリティア 6種）**
- クロンダイク（1枚／3枚めくり）
- スパイダー（1／2／4スート）
- フリーセル
- ピラミッド
- トライピークス（コンボでスコア）
- ゴルフ

**CPUと対戦／オンライン対戦（9種）**
| ゲーム | 人数 |
|---|---|
| 大富豪（革命・8切り・スペ3返し・階段・カード交換、1/3/5回戦） | 2〜5人 |
| ババ抜き | 2〜5人 |
| ジジ抜き | 2〜5人 |
| 七並べ（パス3回／5回） | 2〜5人 |
| スピード（早い者勝ち・リアルタイム） | 2人 |
| ダウト | 2〜5人 |
| 神経衰弱（26枚／52枚） | 1〜5人 |
| ブラックジャック（ディーラーと勝負、チップを競う） | 1〜5人 |
| ポーカー（5カードドロー・チップ制） | 2〜5人 |

CPUの強さは「やさしい／ふつう／つよい」。人数が足りないときはCPUで埋められます。

## オンライン対戦（招待コード）
- 「オンライン対戦」→「部屋をつくる」→ 人数を選ぶと **6けたの招待コード** ができます（1けた目が人数）。
- 「コードを送る」で LINE などに送れます。友だちは「コードで参加」に入力。
- 全員そろうとロビーへ。ホスト（部屋を作った人）がゲーム・CPUの人数・強さを選んでスタート。
- 仕組み：Game Center のリアルタイム対戦（GameKit）。招待コードを `playerGroup` に使うので、同じコードの人どうしだけがつながります。サーバーは不要です。
- ホストがゲームの進行を計算して全員に配り、参加者は操作だけを送ります。途中で抜けた人の席はCPUが代わりに遊びます。
- Game Center の友だちに直接招待を送ることもできます。

## 中身
- `Resources/index.html`, `style.css` … 画面
- `Resources/core.js` … 共通（セーブ・効果音・キャラ）
- `Resources/cards.js` … カードの描画
- `Resources/solo.js` … ソリティア6種
- `Resources/multi.js`, `multi2.js` … 対戦ゲーム9種のルールとCPU
- `Resources/table.js` … 対戦の進行・CPU・同期
- `Resources/net.js` … オンライン（招待コード・ロビー）
- `App/GameCenterManager.swift` … Game Center の接続（招待コード検索・招待・送受信）
- `App/GameView.swift` … 画面表示とアプリの橋渡し（セーブ・振動・共有）

ブラウザで `Resources/index.html` を開くと動作確認できます（同じブラウザの別タブ同士で、オンライン対戦のテストもできます）。

## iPhone への入れ方
`main` に push すると GitHub Actions の「もふもふトランプ iOS / TestFlight」が動き、TestFlight にアップロードされます。
初回だけ App Store Connect で次の作業が必要です。
1. 「マイApp」→「＋」→「新規App」で Bundle ID `com.yosiken0421.mofutrump` のアプリを作成
2. TestFlight の内部テスターに自分を追加
3. （オンライン対戦用）そのアプリで Game Center を有効にする

アプリ作成後にもう一度アップロードしたいときは、Actions の「もふもふトランプ iOS / TestFlight」で Run workflow を押します。

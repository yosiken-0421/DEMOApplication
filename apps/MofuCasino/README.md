# もふもふカジノ

カジノゲームがたくさん入ったゲーム集です。ひとりでも、CPUとでも、1台のスマホをみんなで回しても、友だちとオンラインでも遊べます。
キャラクターは もふぴー・くろにゃ・ぴょんた・ぺんぺん・がおるん（添付イラストをそのまま切り抜いて使用。縦横同じ倍率で縮小するだけで、変形はしていません）。

**コイン・チップはすべて遊び用です。** お金の価値はなく、購入・換金・景品との交換はできません（課金機能もありません）。

## 収録ゲーム（21種）
カジノの人気ランキング（スロット・ブラックジャック・ルーレット・クラップス・バカラ・ビデオポーカー・ポーカーが上位）や、オンラインカジノで伸びているミニゲーム（クラッシュ・プリンコ・マインズ・キノなど）、日本の定番（チンチロ・丁半）を調べて選びました。

**ひとりでマシン（もふコインで遊ぶ・9種）**
| ゲーム | 内容 |
|---|---|
| もふもふスロット | 3×3・5ライン。キャラ絵柄、777でジャックポット、オート回転 |
| ビデオポーカー | ジャックス・オア・ベター（9/6） |
| プリンコ | 8段／12段、リスク ひくい／たかい |
| ロケット | クラッシュ系。自動で受け取る倍率も設定可 |
| 宝さがし | マインズ系。ばくだん1／3／5／10個 |
| ハイ＆ロー | 当てるたびに倍率アップ、いつでも受け取り |
| ビッグホイール | 54マス（1・2・5・10・20・40倍） |
| キノ | 1〜40から最大8個、10個の当たり |
| スクラッチ | 9マスをけずって同じ倍率3つで当たり |

- もふコインは最初 3,000枚。毎日 +500枚のログインボーナス、100枚未満になったら「おこづかい」+1,000枚。
- CPU卓・オンラインで1位になると +300枚。

**カジノ卓（CPU・1台でみんな・オンライン）12種**
| ゲーム | 人数 |
|---|---|
| ブラックジャック（ダブル・スプリット・BJは1.5倍） | 1〜5人 |
| ルーレット（ヨーロピアン、数字・赤黒・奇偶・ダズン・列） | 1〜5人 |
| バカラ（タイ・ペア） | 1〜5人 |
| テキサスホールデム（サイドポット・ブラインド上昇） | 2〜5人 |
| チンチロ（親が交代・ピンゾロ/ゾロ目/シゴロ/ヒフミ） | 2〜5人 |
| もふもふダービー（キャラのかけっこ・オッズ） | 1〜5人 |
| 大小（シックボー） | 1〜5人 |
| スリーカードポーカー（アンティ・ペアプラス） | 1〜5人 |
| クラップス（パス・ドントパス・フィールドなど） | 1〜5人 |
| ドラゴンタイガー | 1〜5人 |
| 丁半 | 1〜5人 |
| ビンゴ（ビンゴマシン演出・自動／手動チェック・ポット総取り×倍率） | 1〜5人 |

- 卓ごとにチップが配られ（1,000／3,000／10,000）、決められたラウンドが終わったときに一番チップが多い人の勝ち。
- **CPUと**：人数が足りない分をCPUで埋められます。強さは「やさしい／ふつう／つよい」。ブラックジャックはベーシックストラテジー、ホールデムは勝率シミュレーションで考えます。
- **みんなで（1台で）**：1台のスマホを順番に回して2〜5人で。CPUを混ぜることもできます。

## オンライン対戦（招待コード）
- 「オンライン対戦」→「部屋をつくる」→ 人数を選ぶと **6けたの招待コード** ができます（1けた目が人数）。
- 「コードを送る」で LINE などに送れます。友だちは「コードで参加」に入力。
- 全員そろうとロビーへ。ホスト（部屋を作った人）がゲーム・CPUの人数・強さ・チップ数を選んでスタート。
- 仕組み：Game Center のリアルタイム対戦（GameKit）。招待コードを `playerGroup` に使うので、同じコードの人どうしだけがつながります。サーバーは不要です。
- ホストがゲームの進行を計算して全員に配り、参加者は操作だけを送ります。途中で抜けた人の席はCPUが代わりに遊びます。

ブラウザで `Resources/index.html` を開くと動作確認できます（同じブラウザの別タブ同士で、オンライン対戦のテストもできます）。

## iPhone への入れ方
`main` に push すると GitHub Actions の「もふもふカジノ iOS / TestFlight」が動き、TestFlight にアップロードされます（Bundle ID も自動で登録されます）。
初回だけ App Store Connect で次の作業が必要です。
1. 「マイApp」→「＋」→「新規App」で Bundle ID `com.yosiken0421.mofucasino` のアプリを作成
2. TestFlight の内部テスターに自分を追加
3. （オンライン対戦用）そのアプリで Game Center を有効にする

アプリ作成後にもう一度アップロードしたいときは、Actions の「もふもふカジノ iOS / TestFlight」で Run workflow を押します。

※ App Store に公開するときは、年齢制限の質問で「シミュレートされたギャンブル」を選ぶ必要があります（TestFlight の内部テストだけなら不要）。

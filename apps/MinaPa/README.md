# みなパ！（みんなでワイワイ ミニゲームパーティー）

友だち・カップル・職場の仲間と、iPhone同士でオンライン対戦／協力できるミニゲーム集です。

## 遊び方
- **みんなであそぶ**：Game Center で友だちを招待（2〜4人）。ロビーで「対戦」か「協力」、ゲーム数（3/5/7本）を選んでスタート。全員が同じお題を同時に遊び、点数で勝負します。
  - 対戦：各ゲームの順位でポイント（1位3pt・2位2pt・3位1pt）。合計で優勝を決めます。
  - 協力：全員の合計点が目標をこえたらクリア。何本クリアできたかを星で表示します。
- **ひとりであそぶ**：好きなミニゲームでハイスコア挑戦、または「おまかせ5本勝負」。

## ミニゲーム（13種）
ふうせんパチン / タワーつみつみ / ピカッと早押し / かずタッチ / いろいろジャッジ / おやつキャッチ / ぴったりストップ /
れんだダッシュ / ひょっこりタッチ / なかまはずれ / けいさんバトル / やじるしスワイプ / おぼえてパネル

## BGM
オリジナル曲をゲーム内で演奏しています（メニュー曲・ゲーム中の曲。残り5秒でテンポアップ）。タイトル画面右下の🎵ボタンでON/OFFできます。

## キャラクター（オリジナル6人）
ヒナタ・ソラ・ミオ・レン・コハク・ユウ（アニメ調デフォルメ。勝敗で表情とリアクションが変わります）

## 中身
- `Resources/index.html` … ゲーム本体（画面・ミニゲーム・キャラ・通信の流れ）
- `App/GameCenterManager.swift` … Game Center の招待・接続・データ送受信
- `App/GameView.swift` … ゲーム画面の表示とアプリとの橋渡し

## iPhone への入れ方
`main` に push すると GitHub Actions の「みなパ！ iOS / TestFlight」が動き、TestFlight にアップロードされます。
初回だけ App Store Connect で次の2つが必要です。
1. 「マイApp」→「＋」→「新規App」で Bundle ID `com.yosiken0421.minapa` のアプリを作成
2. そのアプリの画面で **Game Center を有効にする**（みんなで遊ぶ機能に必要）
